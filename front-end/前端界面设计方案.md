## 一、技术选型

| 项 | 选择 | 理由 |
|----|------|------|
| 框架 | Vue 3（Composition API，`<script setup>`） | 与后端分离既定架构 |
| 构建 | Vite 7 | 快、Node 22 完全兼容 |
| 语言 | JavaScript（非 TS） | 实习项目降低复杂度 |
| 路由 | Vue Router 4 | 登录守卫 + 角色菜单 |
| 状态 | Pinia | 存 token 与用户信息 |
| UI 库 | Element Plus | OA 表格/表单/对话框场景最成熟 |
| HTTP | Axios | 请求/响应统一拦截 |
| 图标 | 内置线性图标组件 AppIcon（圆头描边风格，零依赖） | 菜单/按钮图标，统一现代风格 |

## 五、交互与状态约定

1. Axios 拦截器：请求自动带 `Authorization: <token>`；响应统一判断 `code`——0 放行，401 清 token 跳登录，403 提示无权限，其他 ElMessage.error(msg)。
2. 路由守卫：无 token 访问业务页 → 重定向 /login；已登录访问 /login → 跳首页。
3. 删除、审批等危险操作统一 `ElMessageBox.confirm` 二次确认。
4. 表格操作列：编辑 / 删除 / 详情；分页条固定右下。
5. 时间显示：日期 `YYYY-MM-DD`，时间 `YYYY-MM-DD HH:mm`（前端格式化）。
6. 状态标签配色：审批 0待审=warning(橙) / 1通过=success(绿) / 2驳回=danger(红)；公告 0草稿=info / 1已发布=success；工资 0待发放=warning / 1已发放=success。
